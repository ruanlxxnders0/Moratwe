# Images for Moratwe Marketing Site

The following images need to be created or added to the static/images directory for the marketing site to display correctly:

## Core Images

1. `logo_transparent.png` - The Moratwe logo with transparent background
2. `logo.jpg` - The full Moratwe logo 
3. `hero-image.png` - A hero image showing event management or people at an event

## App Screenshots

1. `app-screenshot-1.png` - Screenshot showing the app's events list
2. `app-screenshot-2.png` - Screenshot showing the QR code scanning functionality
3. `app-screenshot-3.png` - Screenshot showing the user profile or event detail view

## App Store Badges

1. `app-store-badge.svg` - App Store download badge
2. `google-play-badge.png` - Google Play download badge

These images should match the branding of Moratwe and showcase the mobile application features shown in the provided screenshots.

Current dimensions:
- App screenshots: 320px x 693px (portrait)
- Hero image: 600px x 400px (landscape)
- Logo: Various sizes, minimum 200px width recommended
