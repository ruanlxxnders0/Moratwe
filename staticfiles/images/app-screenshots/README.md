# App Screenshots

Based on the provided UI screenshots, you should create the following screenshot files:

1. `app-screenshot-1.png`: This should be an image of the events list screen showing upcoming events like "Tech Conference 2025", "Career Fair 2025", etc. with their dates and locations.

2. `app-screenshot-2.png`: This should be an image of the QR code scanning screen with the frame to position the QR code.

3. `app-screenshot-3.png`: This should be an image of the profile view showing user information and events they are attending.

4. `hero-image.png`: This should be a promotional image showing people at an event or a dashboard view of the application.

These screenshots should be placed in the `static/images/` directory. You can create them by taking screenshots of the actual app or by creating mockups based on the provided UI.
